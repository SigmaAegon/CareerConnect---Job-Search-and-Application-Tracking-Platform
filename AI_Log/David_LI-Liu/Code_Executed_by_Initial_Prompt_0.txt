  🎯 Architecture Decisions Explained

  Why Next.js?
  - Next.js App Router gives us server components and built-in routing. We can add server actions later without building a separate backend. The file-based routing (app/jobs/page.tsx = /jobs
    route) is beginner-friendly.

  Why Tailwind CSS?
  - Utility classes let us style components quickly without switching between CSS files. className="flex gap-4 p-6" is faster than writing CSS classes.
  
  Why shadcn/ui?
  - Components are copied into your codebase (in src/components/ui/), not installed as a black-box npm package. You have full control to customize them.
  
  Why TypeScript?
  - Catches typos and type errors before runtime. If you try to use job.titel instead of job.title, TypeScript will error immediately.
  
  Why dummy data?
  - Building UI first lets us iterate fast. The types in src/types/index.ts define the data structure. Later, we'll replace dummyJobs with real database queries, but the components won't need to
    change much.
